# プライバシーポリシー

電話の追跡 · 最終更新日：2026年11月17日

## 1. 本ポリシーについて

「電話の追跡」（以下「本アプリ」）は、許可した相手に位置を1回ずつ手動で共有する iOS アプリです。本ポリシーは、本アプリが扱う情報、保存先、お客様の選択肢について説明します。本アプリは開発者（以下「当方」）が提供します。連絡先：https://github.com/xxlcmb9/doc/issues。

## 2. 取得する情報

- 共有番号：端末上でランダムに生成される9桁の数字。メールアドレス、電話番号、パスワード、SNS アカウントは不要で、氏名・連絡先・写真も求めません。
- お客様が確認した位置：緯度、経度、高度、タイムスタンプ。共有をタップして確認した場合にのみ送信されます。
- 許可リストとブロックリスト：許可またはブロックした共有番号。ご自身のプロフィールに保存されます。
- お問い合わせ内容：サポートページからご連絡いただいた内容。

## 3. 共有の仕組み

- 自動・バックグラウンド・定時での公開は行いません。チェックインのたびに確認が必要で、キャンセルできます。
- 1回のチェックインで1件のみ送信し、以前の記録を上書きします。位置履歴は保存しません。
- 記録は公開から1時間でアプリ内の表示が期限切れとなり、他の利用者には表示されません。期限切れは表示上のルールであり、クラウド上のファイルは削除されません。ファイルは共有の取り消しまたは ID 削除時に削除されます。
- 端末内地図に自身の位置を表示する設定は任意で、何も共有しません。

## 4. 保存場所

共有記録、許可／ブロックリスト、番号インデックスは、中国本土 ap-nanjing リージョンの Tencent Cloud Object Storage（COS）に、本アプリの認証エンドポイントが発行する一時的な認証情報を用いて保存されます。番号とリストは端末にも保存されます。位置データ専用の分析データベースは別途運営していません。削除後も、クラウド事業者のバックアップに一定期間残る場合があります。

## 5. 第三者サービス

- Tencent Cloud COS：共有記録とリストの保存。
- Google AdMob および Google User Messaging Platform：広告と同意画面。Google は端末識別子、IP アドレス、広告の操作情報を取得する場合があります。
- Apple：App Store、アプリ内課金、決済。支払いカード情報を当方が受け取ることはありません。
- open-elevation.com：地図上で地点を選び高度を照会した場合にのみ、選択した座標を送信します。事前にキャンセルできます。

当方は個人情報を販売しません。

## 6. 広告とトラッキングの選択

広告は無料版を支えるために表示されます。iOS 14.5 以降では必要に応じて App Tracking Transparency の許可を求めます。拒否しても広告は表示されますが、パーソナライズされません。iOS の「設定 → プライバシーとセキュリティ → トラッキング」およびアプリ内の同意オプションで変更できます。

## 7. 安全管理とその限界

通信は HTTPS/TLS と有効期限付きの一時認証情報を使用します。照会前にアプリが双方の設定でブロックと許可リストを確認し、ブロックが優先されます。この制御はアプリ側で行われ、サーバー側で分離されているわけではないため、有効な認証情報を得た第三者がバケット内のオブジェクトを読み取ることや、受け取った相手によるスクリーンショット・複製を防ぐことはできません。開示されても困らない情報のみ共有してください。

## 8. お客様の選択肢

- 共有はいつでも取り消せます（共有記録が削除されます）。
- ブロック／解除が可能です。解除しても許可リストは復元されません。
- 端末内地図での自身の位置表示をオフにできます。
- アプリ内で ID を削除すると、位置、プロフィール、インデックスの登録が削除され、その後端末内データが消去されます。買い切りの購入には影響しません。
- iOS の設定で位置情報の利用を許可しない場合、地図・コンパス・高度ツールは使用できなくなりますが、その他の機能は利用できます。
- サポートリンクから、共有番号に紐づくデータの開示・訂正・削除を請求できます。

## 9. 児童について

本アプリは13歳未満（またはお住まいの国で定める最低年齢未満）の児童を対象としていません。児童のデータを意図的に収集することはありません。児童がデータを共有したと思われる場合はご連絡ください。削除します。
